# WDraft REST API

Backend REST API для мобильного приложения, помогающего с драфтом в игре Brawl Stars.

## Как это работает

1. Пользователь нажимает кнопку в оверлее.
2. Делается скриншот текущего экрана игры.
3. Скриншот отправляется на сервер.
4. Сервер анализирует изображение и состояние драфта.
5. Генерируются рекомендации для выбора бравлеров.
6. Результат возвращается в мобильное приложение и отображается пользователю.

## Стек

* Python
* FastAPI
* PyTorch

## Запуск

1. Клонировать репозиторий

```
https://github.com/Valomeister/wdraft_fast_api.git
cd wdraft_fast_api
```

2. Создать виртуальное окружение (Windows)

```
python -m venv .venv
.venv/Scripts/activate.ps1
```

3. Установить зависимости

```
pip install -r requirements.txt
```

4. Запустить сервер

```
uvicorn app.server:app --reload
```
